1. ผลลัพธ์การเรียนรู้จากการปฏิบัติงาน

ติดตั้งเครื่องมือพัฒนา GUI ด้วย Python และ PySide6 ใช้ผู้ช่วย AI เขียนโปรแกรมสร้างหน้าต่างและวิดเจ็ตพื้นฐาน อ่านโค้ด ทดสอบ แก้ข้อผิดพลาดจาก Traceback และปรับปรุงโปรแกรมให้ตรงสเปกได้

2. จุดประสงค์เชิงพฤติกรรม

  1. ติดตั้ง Python, PySide6 และเครื่องมือพัฒนาได้ถูกต้อง
  2. เขียนสเปกและ prompt สั่ง AI สร้างโปรแกรม GUI ที่มี QLabel, QLineEdit, QPushButton ได้
  3. ระบุส่วนประกอบหลักของโค้ด GUI และทดสอบโปรแกรมตามตารางกรณีทดสอบได้
  4. อ่าน Traceback และแก้ไขข้อผิดพลาดได้ ด้วยความรอบคอบ ซื่อสัตย์ และใช้ AI อย่างรับผิดชอบ

3. เครื่องมือ วัสดุ และอุปกรณ์

  • คอมพิวเตอร์ Windows 10/11 · Python 3.10 ขึ้นไป · PySide6-Essentials · VS Code (หรือ Antigravity) + ส่วนขยาย Python
  • ผู้ช่วย AI: GitHub Copilot ใน VS Code หรือแชต AI บนเว็บ · ไฟล์ประกอบจากหน้าเว็บใบงาน

4. ข้อควรระวัง / กติกา

  1. เก็บงานในโฟลเดอร์ C:\gui-lab ตั้งชื่อไฟล์ภาษาอังกฤษ ไม่เว้นวรรค
  2. ห้ามใส่ข้อมูลส่วนตัว (รหัสผ่าน เลขบัตรประชาชน เบอร์โทร) ลงใน prompt
  3. โค้ดที่ส่งต้องอธิบายได้ ครูจะสุ่มถาม · ต้องทดสอบเองทุกครั้ง อย่าเชื่อ AI ทันที
