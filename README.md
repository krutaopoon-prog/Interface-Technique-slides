# วิชาเทคนิคการอินเตอร์เฟซ 30105-2004 (ปวส. เทคโนโลยีอิเล็กทรอนิกส์)

สื่อการสอนแบบเว็บ (static site) สำหรับ GitHub Pages แยกเป็นรายสัปดาห์ เรียนเขียนโปรแกรม GUI ด้วย Python + PySide6 แบบ **ใช้ AI เป็นผู้ช่วย**
นักเรียนสั่งงาน AI อ่านโค้ด ทดสอบ แก้ และปรับตามวงจร 7 ขั้น โดยไม่ต้องพิมพ์โค้ดเองทั้งหมด

- `index.html` หน้าแรกของวิชา
- `setup.html` คู่มือติดตั้ง Python, VS Code, PySide6-Essentials และผู้ช่วย AI รวมวิธีแก้ปัญหาและการเตรียมห้องคอมแบบไม่มีเน็ต
- `prompts.html` คลังแม่แบบ prompt (สร้างโปรแกรม อธิบายโค้ด แก้ error ปรับทีละเรื่อง สร้างกรณีทดสอบ)
- `w01/slides.html` สไลด์สัปดาห์ที่ 1 จำนวน 97 หน้า (← → / Space, T = สารบัญ, F = เต็มจอ) มีกิจกรรมห้องเรียนสด และตัวจำลอง
- `w01/lab.html` ใบงานปฏิบัติ 1.1 ทำทีละขั้นบนจอ และพิมพ์ใบงาน A4 ได้ 4 หน้า
- `w01/exercises.html` แบบฝึกหัด 42 ข้อ · `w01/quiz.html` แบบทดสอบก่อน/หลังเรียน 20 ข้อ · `w01/answers.html` เฉลยและคู่มือครู (ต้องใส่รหัสครู)
- `w01/code/` ไฟล์ Python ประกอบ lab ทดสอบรันจริงกับ PySide6 6.12 (Python 3.10 และ 3.15)
- `w01/img/` ภาพหน้าจอที่ได้จากการรันโปรแกรมจริง
- `assets/js/sims.js` ตัวจำลอง `loop` `layout` `anatomy` `tb` `ohm` และตัวจับเวลา โหวต สุ่มเลขที่ วิดีโอ
- `assets/js/code.js` ไฮไลต์โค้ด Python, กล่อง Terminal และปุ่มคัดลอก

## แก้เฉลย / เปลี่ยนรหัสครู
1. แก้ `_private/answers-wNN.json` (โจทย์ตัวเลขใส่ `calc` ให้สคริปต์ตรวจสูตรซ้ำได้ · `ws` = แนวคำตอบใบงานและคู่มือครู)
2. รัน `node _private/encrypt-answers.mjs wNN "รหัสครู"` (ต้องมี Node.js 18 ขึ้นไป)
3. อัปโหลดไฟล์ `wNN/answers.enc.js` และ `wNN/check-data.js` ใหม่
4. ส่งเฉลยแบบทดสอบเข้าระบบห้องเรียนสด: `node ../Classroom-live/_private/push-keys.mjs`

โฟลเดอร์ `_private/` และ `ข้อมูล/` อยู่ใน `.gitignore` — ห้ามอัปขึ้น GitHub
