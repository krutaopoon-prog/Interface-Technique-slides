งานที่ 1: ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น

Patient Health Risk Assessment and Registration System

1. บริบทและวัตถุประสงค์ (Business Context & Objective)

องค์กรบริการสุขภาพมีความประสงค์พัฒนาเว็บแอปพลิเคชันเพื่อคัดกรองผู้ป่วยเบื้องต้นก่อนเข้ารับการรักษา ระบบต้องสามารถรับข้อมูลส่วนบุคคล คำนวณค่าดรรชนีมวลกาย (BMI) ประเมินความเสี่ยงตามเงื่อนไขที่กำหนด และออกใบสรุปผลการคัดกรองเพื่อลดเวลาการทำงานของเจ้าหน้าที่หน้าร้าน

2. ขอบเขตและข้อกำหนดเชิงฟังก์ชัน (Functional Requirements)

  • การตรวจสอบความถูกต้องของข้อมูล (Input Validation): ระบบต้องตรวจสอบข้อมูลป้อนเข้า (ชื่อ-นามสกุล, อายุ, น้ำหนัก, ส่วนสูง) หากพบช่องว่างหรือค่าที่ไม่ถูกต้อง ต้องแสดงข้อความเตือนและปฏิเสธการประเมินผล
  • การประเมินและจัดกลุ่มความเสี่ยง (Risk Assessment Logic):
    • คำนวณค่า BMI = น้ำหนัก (kg)( ส่วนสูง (cm) ÷ 100 )²
    • ประเมินระดับความเสี่ยงจาก BMI ร่วมกับพฤติกรรมความเสี่ยง (เช่น การสูบบุหรี่ หรือโรคประจำตัว)
    • จัดจำแนกเป็น 3 ระดับ: ความเสี่ยงต่ำ (Low Risk), ความเสี่ยงปานกลาง (Moderate Risk), ความเสี่ยงสูง (High Risk)
  • การแสดงผลลัพธ์ (Result Display & Summary): แสดงหน้าต่างสรุปผลข้อมูลผู้ป่วย ระดับความเสี่ยง และข้อแนะนำการปฏิบัติตน

3. ข้อกำหนดส่วนติดต่อผู้ใช้งาน (MUI Components Requirement)

  • Structure & Layout: Container, Paper, Grid, Stack
  • Inputs: TextField (รับค่าตัวอักษรและตัวเลข), RadioGroup / Radio (เลือกพฤติกรรมความเสี่ยง), Select / MenuItem (เลือกกลุ่มโรคประจำตัว), Button (ปุ่มประเมินผลและปุ่มล้างข้อมูล)
  • Feedback & Displays: Alert (แจ้งเตือนความผิดพลาด), Dialog / DialogTitle / DialogContent / DialogActions (หน้าต่างสรุปผลการประเมิน), Chip (แสดงสถานะระดับความเสี่ยงด้วยสีสัญลักษณ์)

งานที่ 2: ระบบบริหารจัดการคำสั่งซื้อและคลังสินค้าหน้าร้าน

Point of Sale and Inventory Management System

1. บริบทและวัตถุประสงค์ (Business Context & Objective)

สถานประกอบการค้าปลีกต้องการระบบบริหารจัดการรายการสินค้า คำนวณราคาสินค้าหน้าร้าน พร้อมตัดสต็อกสินค้าในระบบแบบเรียลไทม์ เพื่อเพิ่มประสิทธิภาพการขายและลดความผิดพลาดในการคิดเงิน

2. ขอบเขตและข้อกำหนดเชิงฟังก์ชัน (Functional Requirements)

  • การจัดการรายการสินค้าและสต็อก (Inventory Control): ระบบต้องแสดงรายการสินค้าพร้อมจำนวนคงเหลือ หากสินค้าชิ้นใดมีจำนวนคงเหลือน้อยกว่า 5 ชิ้น ระบบต้องแสดงสถานะเตือนสินค้าใกล้หมด
  • การคำนวณคำสั่งซื้อและส่วนลด (Transaction Calculation):
    • คำนวณราคารวมตามรายการสินค้าที่เลือกและจำนวนที่ระบุ
    • คำนวณภาษีมูลค่าเพิ่ม (VAT 7%) และการประยุกต์ใช้โค้ดส่วนลด (Discount Code)
    • คำนวณเงินทอนและแสดงใบเสร็จรับเงินย่อ
  • การควบคุมสถานะการขาย (Status Control): สามารถเปิด-ปิดการจำหน่ายสินค้าแต่ละรายการได้ทันที

3. ข้อกำหนดส่วนติดต่อผู้ใช้งาน (MUI Components Requirement)

  • Navigation & Header: AppBar, Toolbar, Badge (แสดงจำนวนรายการในตะกร้า)
  • Data Presentation: Card, CardMedia, CardContent, CardActions (แสดงรายการสินค้า), Table, TableHead, TableRow, TableCell (ตารางรายการในตะกร้าและใบเสร็จ)
  • Inputs & Controls: Switch (เปิด/ปิดสถานะการขาย), TextField (ช่องใส่โค้ดส่วนลดและจำนวนเงินที่รับ), IconButton (เพิ่ม/ลด/ลบ รายการสินค้า)
  • Feedback: Snackbar (แจ้งเตือนเมื่อเพิ่มสินค้าลงตะกร้าสำเร็จ), LinearProgress (แสดงสัดส่วนสต็อกสินค้าคงเหลือ)

งานที่ 3: ระบบติดตามและบริหารจัดการงานโครงการองค์กร

Enterprise Project Task & Workflow Tracking System

1. บริบทและวัตถุประสงค์ (Business Context & Objective)

ฝ่ายบริหารโครงการต้องการระบบสำหรับติดตามความก้าวหน้าของงาน (Task Tracking) จัดลำดับความสำคัญ มอบหมายผู้รับผิดชอบ และสรุปภาพรวมสถานะการดำเนินงาน เพื่อใช้ในการประชุมติดตามงานประจำสัปดาห์

2. ขอบเขตและข้อกำหนดเชิงฟังก์ชัน (Functional Requirements)

  • การบันทึกและมอบหมายงาน (Task Creation & Assignment): บันทึกชื่องาน รายละเอียด ผู้รับผิดชอบ วันกำหนดส่ง (Due Date) และระดับความสำคัญ (Priority)
  • การจัดการสถานะและคัดกรองข้อมูล (Workflow State Transition & Filtering):
    • เปลี่ยนสถานะงานได้ 3 ระดับ: To Do, In Progress, Completed
    • คัดกรอง (Filter) งานตามผู้รับผิดชอบ หรือตามระดับความสำคัญ
  • การคำนวณดรรชนีความก้าวหน้า (Progress Analytics): คำนวณเปอร์เซ็นต์ความสำเร็จของโครงการรวมอัตโนมัติ
    Progress % = จำนวนงานที่ Completedจำนวนงานทั้งหมด × 100

3. ข้อกำหนดส่วนติดต่อผู้ใช้งาน (MUI Components Requirement)

  • Layout & Organization: Box, Stack, Tabs, Tab (สลับมุมมองระหว่าง รายการงานทั้งหมด / งานที่ทำเสร็จแล้ว)
  • Data Display: DataGrid หรือ Table (ตารางแสดงรายการงานพร้อมระบบ Sorting/Pagination), Avatar (แสดงรูป/อักษรย่อผู้รับผิดชอบ), Chip (แสดง Priority: High/Medium/Low)
  • Inputs & Actions: Fab (ปุ่ม Floating Action Button สำหรับเพิ่มงานใหม่), Select / MenuItem (เลือกผู้รับผิดชอบและสถานะ)
  • Feedback & Indicators: LinearProgress / CircularProgress (แสดงเปอร์เซ็นต์ความก้าวหน้าโครงการ), Tooltip (แสดงคำอธิบายเพิ่มเติมเมื่อเอาเมาส์ชี้)

เกณฑ์การจัดทำและส่งมอบงาน (Student Project Deliverables)
