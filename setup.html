🧰 คู่มือติดตั้งเครื่องมือ

Python + VS Code + PySide6 + ผู้ช่วย AI บน Windows 10/11 · ใช้เวลาประมาณ 30–40 นาที (ขึ้นกับความเร็วเน็ต)

1. Python2. VS Code3. โฟลเดอร์ + venv4. PySide65. ผู้ช่วย AIปัญหาที่เจอบ่อยสำหรับครู

1. ติดตั้ง Python

  1. เข้า python.org/downloads โหลด Python install manager (หรือค้นหา “Python install manager” ใน Microsoft Store)
  2. ติดตั้งแล้ว เปิด Terminal ใหม่ (PowerShell) พิมพ์ 
    py install 3.15
  3. ถ้าถามว่าจะเพิ่มโฟลเดอร์ลง PATH ไหม ให้ตอบ y
  4. ตรวจ: 
    python --version
    Python 3.15.x (PySide6 6.12 ใช้ได้กับ Python 3.10 ขึ้นไป)

ที่มา: Python Software Foundation, Using Python on Windows · PySide6 บน PyPI

2. ติดตั้ง VS Code (หรือ Antigravity)

  1. โหลดจาก code.visualstudio.com ติดตั้งตามค่าเริ่มต้น (ติ๊ก “Add to PATH” ได้)
  2. เปิด VS Code → กด Ctrl+Shift+X → ค้นหา Python (ผู้ผลิต Microsoft) → Install
💡 เครื่อง RAM 4 GB ใช้ VS Code (ต้องการ RAM ประมาณ 1 GB) · Google Antigravity มี AI agent ในตัว ใช้งานหนักกว่า เหมาะกับเครื่องที่บ้านที่สเปกดี หน้าตาและวิธีติดตั้งส่วนขยาย Python คล้าย VS Code (VS Code requirements · Antigravity docs)

3. สร้างโฟลเดอร์งาน + venv

venv = กล่องเครื่องมือส่วนตัวของโปรเจกต์ ไลบรารีที่ติดตั้งจะอยู่ในกล่องนี้ ไม่ปนกับงานอื่น

  1. VS Code → File → Open Folder… → สร้างและเลือกโฟลเดอร์ C:\gui-lab (ใช้ชื่อสั้น ๆ ไม่มีภาษาไทย ไม่เว้นวรรค)
  2. เปิด Terminal ใน VS Code: Ctrl+` (ปุ่มใต้ Esc) แล้วพิมพ์ 
    python -m venv .venv
.venv\Scripts\Activate.ps1
    (.venv) PS C:\gui-lab>
  3. VS Code มักถามว่าจะใช้ environment นี้ไหม → ตอบ Yes (หรือคลิกเลข Python มุมขวาล่าง เลือกตัวที่มี .venv)

อีกวิธี: กด Ctrl+Shift+P → Python: Create Environment → Venv · ที่มา: venv documentation

4. ติดตั้ง PySide6

pip install PySide6-Essentials
Successfully installed PySide6-Essentials-6.12.0 shiboken6-6.12.0
📦 ทำไมใช้ PySide6-Essentials? ดาวน์โหลดราว 83 MB มีทุกอย่างที่ใช้ในหน่วยแรก ๆ (หน้าต่าง ปุ่ม ช่องพิมพ์ เครือข่าย และ Qt Designer) ส่วน pip install PySide6 ตัวเต็มต้องโหลดราว 260 MB (รวม WebEngine) ซึ่งยังไม่จำเป็น · หน่วยที่ใช้พอร์ตอนุกรมและกราฟ จะติดตั้งเพิ่ม pip install PySide6-Addons (ราว 40 MB)

ตรวจเครื่อง

ดาวน์โหลด check_setup.py ไว้ใน C:\gui-lab แล้วรัน 

python check_setup.py

ข้อความ PySide6 เวอร์ชัน: 6.x และหน้าต่าง “✅ เครื่องพร้อมแล้ว!” เด้งขึ้นมา

ขนาดไฟล์อ้างอิงจาก PyPI (PySide6 6.12.0) และทดสอบติดตั้งจริงบน Windows 11 กับ Python 3.15.2 เมื่อ 30 ต.ค. 2569

5. เปิดผู้ช่วย AI (เลือก 1 ทาง)

🅰️ GitHub Copilot ใน VS Code

  1. คลิกไอคอน Copilot ที่แถบล่าง (Status Bar) → Use AI Features
  2. ล็อกอินด้วยบัญชี GitHub (ยังไม่มีให้สมัครที่ github.com) → ถ้ายังไม่มีแผน ระบบจะให้ใช้ Copilot Free ซึ่งมีโควตารายเดือน
  3. นักศึกษาที่ยืนยันตัวกับ GitHub Education ใช้ Copilot Student ได้ฟรี

🅱️ แชต AI บนเว็บ (เครื่องสเปกต่ำ / โควตาหมด)

เปิด Gemini, ChatGPT หรือ Claude ในเบราว์เซอร์ → พิมพ์ prompt → คัดลอกโค้ดมาวางในไฟล์ .py ใน VS Code · วงจรทำงาน 7 ขั้นเหมือนเดิมทุกอย่าง

ที่มา: Set up Copilot in VS Code · Plans for GitHub Copilot · โปรดตรวจเงื่อนไขอายุและบัญชีของแต่ละบริการก่อนใช้

👩‍🏫 สำหรับครู: เตรียมห้องคอมก่อนคาบ

  1. ติดตั้ง Python และ VS Code ไว้ก่อนทุกเครื่อง (ประหยัดเวลาคาบได้ 20 นาที)
  2. เตรียมไฟล์ติดตั้ง PySide6 ใส่ USB / แชร์โฟลเดอร์ (ทำบนเครื่องที่มีเน็ต และ Python รุ่นเดียวกับห้องคอม): 
    pip download PySide6-Essentials -d D:\wheels
    นักเรียนติดตั้งจาก USB โดยไม่ใช้เน็ต: 
    pip install --no-index --find-links D:\wheels PySide6-Essentials
  3. ติดตั้ง Python แบบไม่มีเน็ตก็ได้: py install --download=D:\pyoffline 3.15 บนเครื่องที่มีเน็ต แล้ว py install --source=D:\pyoffline\index.json 3.15 บนเครื่องในห้อง
  4. ลองทำ ใบงาน 1.1 เองก่อน 1 รอบ และอ่านคู่มือครูในหน้าเฉลย 🔒

คำสั่ง pip download / --no-index --find-links เป็นวิธีมาตรฐานของ pip · คำสั่ง py install --download/--source จาก Using Python on Windows
